# 🍊 Хурма · База знаний для квиза

Тренировочный сайт квиз-команды «Хурма»: рейтинги фильмов, сериалов, музыки и случайные факты для эрудиции.

## Запуск

\`\`\`bash
npm install
npm run dev
\`\`\`

Открыть [http://localhost:3000](http://localhost:3000).

## Стек

- React 18
- Vite 6
- Zustand (с persist в localStorage)
- Чистый CSS

## Структура

- `src/data.js` — статические данные (фильмы, сериалы, музыка, факты)
- `src/api.js` — имитация API, легко заменить на реальный источник
- `src/store.js` — Zustand-хранилище с автообновлением и избранным
- `src/App.jsx` — UI: табы, карточки, таймер, факты
- `src/styles.css` — тёмная тема «Хурма»

## Особенности

- Рейтинги «обновляются» каждые 5 минут (небольшое колебание значений).
- Избранное и оценки сохраняются в localStorage.
- Таймер на 60 секунд для тренировочных туров.
- Полностью адаптивно под мобильные.

## Замена данных на реальные API

Откройте `src/api.js` и замените `fetchAllRatings` на реальный запрос.
В среде StackBlitz можно использовать серверный прокси, чтобы обойти CORS.
